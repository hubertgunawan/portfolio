A portfolio should prove skills, not just list them. I wanted this site to be built, tested, and deployed the same way I'd build a production system.

## Key decisions

- **Static first.** Next.js static export keeps pages fast and keeps the site up even if any API is down.
- **Content as data.** Experience, skills, and projects live in typed data files; case studies are MDX. The web resume and the home page read from the same source.
- **Self-hosted on AWS.** S3 + CloudFront instead of a managed platform, with infrastructure as code for reproducible rebuilds.
- **Build-time integrations.** The latest blog posts are pulled from the blog's RSS feed at build time, with a fallback if the feed is unavailable.
