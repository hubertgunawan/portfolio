## Problem

Deepfake videos can look convincing frame by frame. But real faces carry a faint physiological signal: skin colour changes slightly with each heartbeat. Generated faces usually don't reproduce that signal consistently. My thesis asked whether that signal could be used to tell real videos from fakes.

## Model design

- **rPPG features.** Remote photoplethysmography (rPPG) estimates a pulse signal from tiny colour changes in facial skin across video frames.
- **LSTM classifier.** Because the signal is a time series, an LSTM network learns how it evolves over time and classifies each clip as real or fake.

## Limitations & safety

- rPPG is sensitive to lighting, compression, motion, and video resolution, so performance can drop on low-quality footage.
- Newer generation methods may learn to imitate physiological signals, so this should be one signal among several, not a final verdict.

## Tech stack

## Lessons

- Good features matter as much as model choice: a clean pulse signal made the classifier's job much easier.
- Evaluation needs to reflect real-world video quality, not just clean benchmark clips.
