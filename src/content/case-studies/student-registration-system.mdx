## Problem

New student registration and administrative records were handled with paperwork and disconnected tools. The university needed a single web application for registration and record management.

## My role

Assistant Lecturer. I designed and built the web application.

## Key decisions

- **One system for both sides.** Applicants and administrative staff worked from the same records, so there was a single source of truth.
- **Validation at entry.** Checking data when it was submitted reduced clean-up work for staff later.
