## Key decisions

- **React front end on a REST API.** A clear contract between client and server let each side change independently.
- **Docker and Kubernetes on AWS.** Containerized services gave consistent environments and repeatable deploys.
- **Automated tests.** Unit tests and test automation protected releases from regressions.
